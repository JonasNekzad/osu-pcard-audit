Recommended approach

Rules-based search is the fastest and uses no model tokens, but it can miss a relevant policy when the question uses different wording. The LLM without a vector index can interpret natural language, yet sending all 98 policies on every request increases token use and response time. The unsupported-answer check flags a response when its policy title or supporting sentence cannot be verified.

The preferred approach is the LLM with the vector index because it retrieves the five most relevant policies before generating an answer. This keeps the prompt focused, reduces token use, and makes the cited policy easier to verify.
